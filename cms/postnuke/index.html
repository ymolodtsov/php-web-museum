PostNuke

2005

Released2001
Version shown0.750
Peak era2002–2005
Written inPHP
DatabaseMySQL
StatusDiscontinued — later renamed Zikula

PostNuke began in 2001 as a fork of PHP-Nuke, started by developers who wanted open development and cleaner, more secure code. It kept the familiar portal layout of side blocks, news stories, topics, polls, downloads and web links, and added a permissions system, a module API and later the Xanthia theme engine. Clubs, schools, hobby groups and small communities ran it on shared hosting, usually with a phpBB-based forum module bolted on. Progress on the planned 0.8 rewrite was slow while Joomla and Drupal took its users, and in 2008 the project was renamed Zikula.
