    I wanted to use display: inline-block for a list of thumbnails (to avoid floats). Works in Firefox 3, Safari, Opera, and IE with the hasLayout trick. Firefox 2 just ignores it. Is there a solution?
    • CommentAuthorzoom1
    • CommentTime7 days ago
     
    Firefox 2 needs display: -moz-inline-box (or -moz-inline-stack). Put it before inline-block, so Firefox 3 uses the standard one:

    li { display: -moz-inline-stack; display: inline-block; zoom: 1; *display: inline; }

    The last two are for IE6/7.
