People keep asking how I colour, so here's my process for a typical page:


  1. Scan inks at 600dpi, bitmap mode, clean up, then convert to greyscale and then RGB.
  2. Put the lineart layer on top, set to Multiply.
  3. Flats: a new layer under the lines. Magic wand with anti-alias OFF on the lineart, fill each area with a flat colour. Every object gets its own colour, even if it'll end up the same.
  4. Lock transparency on the flats layer, then shade on a layer above with a hard brush, layer set to Multiply.
  5. Lighting on another layer set to Screen or Overlay.
  6. Flatten a copy, resize to 900 pixels wide, Save for Web as JPG around quality 70.


The flats step is boring but it makes everything after it ten times faster.
