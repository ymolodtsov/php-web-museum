gcc 4.0: invalid lvalue in assignment

Building an old release of a tool from source and gcc 4.0 stops with:

Code:

parse.c:212: error: invalid lvalue in assignment

The line is ((char *)p) += len; and it builds fine with 3.4. What changed?

Re: gcc 4.0: invalid lvalue in assignment

Cast-as-lvalue was a GNU extension and it was removed in 4.0. Write it as p = (char *)p + len; or build that one package with gcc-3.4.

(setq inhibit-startup-message t)
