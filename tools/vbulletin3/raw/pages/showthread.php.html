Free WAP using 1.40.0R without editing homepage!
I hope this post isn't too long or complicated ...

This is thanks to hymy's initial posting (on HoFo) of this using wap.google.com (though it didnt quite work)

This requires no programs/software/cables or anything. Just a V710 on Verizon Wireless.
This just uses your minutes, like any other WebSession usage.

1. Go to Programming Menu(type this quickly!): Menu + 0 + 73887 + * (Security Code: 000000)
2. Go to Web Sessions
3. Create New Entry
4. Give it a name
5. Change the Gateway IP to 66.218.71.218 (wap.oa.yahoo.com)
6. Server Type: HTTP
7. Change Port 1 to 80
8. Save

9. Launch it
10. You will go to the http://wap.oa.yahoo.com page (if you don't, it is because of the cache setting in the WebSession Edit menu - just hit Menu > Refresh to get to the wap yahoo page).
11. Take a snapshot (Menu > snapshot > take snapshot)

OK ... you should be on the wap.oa.yahoo.com page.
You can browse some of those links, but not all (for example, the News and Sports work, but the Games link doesn't).
One good thing is that the Login/SignIn works! However, there is no Web Search that I can find.
I'm not sure why there is no Search link, because there is one if you use your browser and go there: http://66.218.71.218

*** All of the above is done WITHOUT using a free proxy or WAP server - this is using yahoo's 66.218.71.218 on port 80!


There may be other sites that will work this way as well. Some of you can experiment and let us know.


Now, if you want to do more than just browse some stuff on wap.oa.yahoo.com, you can go back into your WebSession menu:
1. Create a New Entry, or Edit one of your existing ones.
2. Use a valid HTTP proxy or WAP server (use a free proxy search site to find one, or use your own proxy/WAP server).
3. Set the Gateway IP, Server Type, and the Ports appropiately.
4. Launch this newly edited/created WebSession.
5. You should get an error message (though this might depend on your Cache setting). Click Menu > snapshots and choose the Yahoo snapshot you saved.
You can now use all the links on the Yahoo page.
Though I'm not sure how useful that Yahoo page is - I really havent checked it out much using my V710, other than looking for the Search Web feature, which I couldn't find.

Is this useful to anyone? :haveadrink

One of the big things to be learned by this, is that Snapshots is the way to bypass the http://homepage.
You can Edit your WebSession and use different IP addresses and Port 80, and create Snapshots that you can then use on your free proxy WebSession without having to edit the homepage!
Just get IP addresses for your favorite sites, and get some Snapshots.
This ought to get you something if you dont want (or can't) edit your homepage.

EDIT: an easier method to get new Snapshots is to email some links to your V710's phonenumber@vtext.com address. You can read the text message and select Menu > Go To and select a link. Once the page loads, you can save a Snapshot. This will only work if you are using a WebSession with a valid proxy or WAP server (not the Yahoo IP on Port 80).

On a text message sent to your V710 at phonenumber@vtext.com, you see the links as text. BUT, click on Menu > Go To and you will be given a list of the links in that text message!!!!!
You can send to phonenumber@vzwpix.com and the links show up as links in the message. But sending to your V710 @vzwpix.com will cost more than @vtext.com ... and, like you noticed, it takes a lot longer for the @vzwpix.com messages.

Snapshots are not bookmarks. A bookmark is a link to a page. A Snapshot is the actual source code of the page stored locally on your V710.
When you View a Snapshot, you are just viewing a copy of the stored page.
The content won't change on the stored (snapshot) page - so, you want Snapshots that contain links to the pages/places you want to go.

If you want to leave the Yahoo site and browse the web, you are going to need a valid HTTP proxy or WAP server.

Search google for free proxy and you'll find sites with lists of proxys. here's one:
http://www.proxy4free.com/page1.html

Set up a new WebSession with the info from that free proxy, like this:
homepage: http://homepage (you can't edit this if you have 1.40.0R firmware)
userid: (blank, or as required)
password: (blank, or as required)
gateway IP 1: 66.11.111.111 (this must be a valid HTTP proxy or WAP server, 66.11.111.111 is NOT valid. I made it up)
gateway 1: (blank)
service type 1: HTTP proxy (or WAP server)
port 1: 3128 (the proxy or server will provide this)
E2E port 1: 3128 (use same as above, unless otherwise note)
LXL port 1: 3128 (use same as above, unless otherwise note)
all the 2's can be left at the default

Since you cannot edit the homepage, you are going to get an error when you try and Launch the new WebSesion.
This makes it hard to tell if you found a valid proxy or not (but you can always pay $4.99/month).
With homepage: http://homepage in your WebSession, there are 2 ways to load a web page (and tell if your proxy is valid!):
1. Launch the WebSession, clear the error message, click menu > menu > Snapshots > View Snapshots and select one!!! (unless you dont have any Snapshots)
2. Send yourself a text message with some url's. Read the text message and click menu > Go To > and select the link to go to.

If you get this working, just send yourself text messages with url's. Once you Go To a url, you can click Menu > Snapshots > Take Snapshot > and save it.
Now you can load that page anytime, by simply Viewing that Snapshot. A Snapshot is just a copy of the page, though, with the content that was on it at the time of the Snapshot, though you can Update this at anytime from the Snapshots menu.

For more info, here is a big thread on Verizon and Mobile Web:
http://www.howardforums.com/showthre...hreadid=557099
