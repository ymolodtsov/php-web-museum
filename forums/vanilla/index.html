Vanilla

2008

Released2005
Version shown1.1.5a
Peak era2006–2009
Written inPHP
DatabaseMySQL
StatusDiscontinued (succeeded by Vanilla 2)

Vanilla was written by Mark O’Sullivan of Lussumo and first released in 2005, with version 1.0 following in 2006. It dropped the usual board-and-forum hierarchy: the front page was a single list of discussions sorted by latest activity, categories worked more like labels, and the default style showed little beyond names, counts and dates. Everything else came from add-ons, and the community wrote hundreds of them. Its tidy XHTML and CSS made it popular with web designers, blogs and small software projects. In 2009 O’Sullivan and Todd Burry founded Vanilla Forums Inc. and rewrote the software as Vanilla 2; volunteers kept 1.x patched until 2012.
