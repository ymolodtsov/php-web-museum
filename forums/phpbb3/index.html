phpBB 3

2008

Released2007
Version shown3.0.2 (prosilver style)
Peak era2008–2012
Written inPHP
DatabaseMySQL
StatusSuperseded by phpBB 3.1 (2014); phpBB itself is still maintained

phpBB 3.0, codenamed Olympus, took five years to arrive: work started soon after 2.0 shipped in 2002, and the final release came out in December 2007 after a long run of betas and release candidates. It replaced subSilver with prosilver, a rounded blue style built on CSS instead of tables, and added a User Control Panel, a permission system with roles, friends and foes, bookmarks, attachments and moderator tools on every topic page. Many boards upgraded slowly, because their phpBB 2 MODs did not carry over, and regulars complained about the new look for months. The 3.0 line was supported until 2017; phpBB 3.1 (2014) added extensions, and the 3.3 branch is still maintained.
